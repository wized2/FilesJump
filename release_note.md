## What's new in 1.0.0

- First full stable release
- Opens AOSP DocumentsUI (Files) and closes itself
- Robust multi-strategy launch (OEM-friendly)
- Adaptive Material You folder icon
- Signed release builds (stable + beta)

### Notes

- Does not unlock `Android/data` / `Android/obb` (standard scoped storage)
- If Files is missing on the device, the shortcut exits with a short toast
